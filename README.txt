GENKI KANJI PWA

This is a real installable web-app package. It must be hosted on HTTPS for
Safari/iPhone Home Screen installation and service-worker/offline features.

Files:
- index.html
- manifest.webmanifest
- sw.js

Important:
The uploaded Genki PDF is scanned/image-based, so this build intentionally
does NOT invent readings/meanings. The sample deck currently contains only
10 verified-looking kanji placeholders for the app shell. Before treating
the deck as study material, the remaining cards and source details must be
populated from the uploaded Genki pages.

Hosting options:
1. GitHub Pages
2. Netlify
3. Cloudflare Pages

After hosting:
Safari -> open the HTTPS URL -> Share -> Add to Home Screen.
